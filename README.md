# 🐳 docker-lite-monitor

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Zero Dependency](https://img.shields.io/badge/Dependencies-Zero-brightgreen.svg)](https://github.com/MobileConduit)

A self-contained, single-file Docker supervisor dashboard that queries container states directly via the local Docker daemon and provides an ultra-fast HTML view without bulky third-party agents.

```bash
python monitor.py
# Open http://localhost:9090
```
